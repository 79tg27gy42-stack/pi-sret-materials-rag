# PI-SRET Rule Specification

This specification mirrors `src/sret_materials_rag/evaluation/constraints.py` as used for the final revision. The rules are deterministic post-generation diagnostics over `(question, answer)` and extracted spans `z = Phi(q,y)`. They are not a complete theory of materials validity.

Common exception predicate: a rule is suppressed only when the local clause containing the triggering span rejects, invalidates, or explicitly qualifies that span. Generic source unreliability elsewhere in the answer does not suppress an unrelated later claim.

| Rule ID | Label | Family | Level | Applicability predicate | Breach predicate | Exception predicate | Threshold | Required extracted spans | Normalization | Trigger example | Non-trigger / exception example |
|---|---|---|---|---|---|---|---|---|---|---|---|
| BG-01 | `non_negative_band_gap` | Band gap | L0 | Answer or question-specified terse answer contains a band-gap value in eV. | Value is below 0 eV. | Local claim rejects the value as invalid/unreliable. | 0 eV | band-gap value, unit, local clause | signed decimal eV | `band gap is -0.3 eV` | `reports -0.3 eV, but this value is invalid` |
| BG-02 | `band_gap_physical_range` | Band gap | L0 | Answer or question-specified terse answer contains a band-gap value in eV. | Value exceeds broad diagnostic guard. | Local claim rejects or qualifies the value. | 15 eV | band-gap value, unit, local clause | signed decimal eV | `band gap is 22 eV` | `the 22 eV entry is an unreliable source error` |
| FE-01 | `formation_energy_typical_range` | Formation energy | L1 | Answer or formation-energy question contains eV/atom or formation-energy expression. | Value lies outside diagnostic interval. | Local claim rejects/qualifies the value. | `[-4, 1]` eV/atom | formation-energy value, unit, local clause | eV/atom and eV per atom normalized | `formation energy is 2.5 eV/atom` | `2.5 eV/atom is reported, but the record is invalid` |
| FE-02 | `elemental_formation_energy_reference_conflict` | Formation energy | L1 | Question asks formation energy for a single element and answer gives eV/atom value. | Positive value above elemental-reference tolerance. | Local clause indicates allotrope, metastable phase, nonstandard reference, or value rejection. | 0.05 eV/atom | question element, formation-energy value, local clause | valid element symbol from question | `What is the formation energy of Si? ... 0.37 eV/atom` | `0.37 eV/atom relative to a metastable phase` |
| ST-01 | `cautious_stability_claim` | Stability | L1 | Answer asserts thermodynamic stability using stable/stability patterns. | No thermodynamic evidence phrase is present. | Claim is negated, non-thermodynamic stability is named, or local claim states missing/unreliable evidence. | none | stability assertion, evidence phrase if present | local sentence/clause scope | `The material is stable.` | `The context does not provide formation energy or hull evidence for stability.` |
| ST-02 | `positive_formation_energy_stability_conflict` | Stability | L1 | Stability assertion and positive formation-energy value are both present. | Positive formation energy is asserted as compatible with stability. | Formation-energy span has phase/reference qualification or is rejected. | value > 0 eV/atom | stability assertion, formation-energy value, qualifier | eV/atom | `formation energy is 0.8 eV/atom and the compound is stable` | `0.8 eV/atom relative to a nonstandard reference` |
| CF-01 | `valid_chemical_symbols` | Chemical formula | L0 | A formula-like span is detected and passes candidate filters. | Parsed element symbol is outside the supported element table, except placeholder `M`. | Local claim rejects the malformed formula. | valid element symbols | formula span | element-token reconstruction | `Xx2O3 is the compound` | `Xx2O3 appears in an invalid source entry` |
| TEMP-01 | `non_negative_absolute_temperature` | Temperature | L0 | Answer or temperature question contains Kelvin value. | Value is below 0 K. | Local claim rejects the value. | 0 K | temperature value, unit, local clause | K/Kelvin | `critical temperature is -5 K` | `-5 K is not physically valid` |
| PRES-01 | `non_negative_pressure` | Pressure | L0 | Answer or pressure question contains Pa/MPa/GPa value. | Value is negative. | Local claim rejects the value or names a stress/tensile sign convention. | 0 Pa | pressure value, unit, local clause | Pa/MPa/GPa | `pressure is -2 GPa` | `-2 GPa under a tensile stress sign convention` |
| COND-01 | `conductivity_band_gap_consistency` | Conductivity/band gap | L1 | Answer contains metallic/metal or insulator/insulating language and a band-gap value. | Metallic claim has gap > 0.1 eV, or insulating claim has gap < 0.1 eV. | Local band-gap claim rejects the value. | 0.1 eV | conductivity term, band-gap value | signed decimal eV | `metallic with a band gap of 1.2 eV` | `the 1.2 eV value is flagged as unreliable` |
| STRUCT-01 | `crystal_system_space_group_consistency` | Structure | L1 | Answer names a crystal system and a space-group number. | Space-group number is valid but outside the system range. | Local claim rejects the assignment. | International Tables ranges 1-230 | crystal-system term, space-group number | integer space-group number | `cubic, space group 62` | `space group 62 is not compatible with cubic symmetry` |
| SC-01 | `cautious_superconductivity_claim` | Superconductivity | L1 | Answer asserts superconductivity/superconductor/superconducting behavior. | No local transition or measurement evidence is present. | Local claim rejects, negates, or explicitly marks evidence as absent/unsupported. | none | superconductivity assertion, evidence phrase if present | local clause after removing negated evidence phrases | `It is a superconductor.` | `There is no evidence that it superconducts.` |

Supported evidence phrases include formation energy, energy above hull, hull distance, convex hull, thermodynamic analysis, transition temperature, superconducting transition, measured, measurement, resistivity, zero resistance, magnetic susceptibility, and Meissner. Supported qualifiers include invalid, unreliable, outdated, incorrect, noisy, unsupported, cannot be used, metastable, allotrope, relative to, and with respect to.
